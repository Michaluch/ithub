Завдання: "Керування даними" (C#)

Тут немає повноцінного компілятора в браузері, тому перевірка — за шаблоном. Пиши синтаксис акуратно.

1

Профіль гравця

Напиши оголошення змінних: nickname (рядок "Cyber_Kid"), level (число 10), isOnline (логічне true) та виведи їх через Console.WriteLine.

Program.cs
2

Обчислення площі

Створи дві змінні a та b зі значеннями 5 та 8. Створи area як їх добуток. Виведи результат.

area.cs
3

Магія імен (Case Sensitivity)

Виправ помилку в коді, враховуючи регістр літер:

int myScore = 100;
Console.WriteLine(MyScore);
💻

Завдання для VS Code

Скопіюйте ці умови та реалізуйте їх у проєкті dotnet new console.

🚀 Задача "Баланс"

Створіть decimal balance = 5000m. Опишіть покупку за 1200 та зарплату 2500 (через +=/-=). Виведіть фінальний баланс.

📦 Задача "Типи"

Створіть змінні різних типів (int, double, string, bool) і виведіть їх в одному рядку через інтерполяцію: $"...".

🧮 Задача "Ділення"

Порівняйте результат 10 / 3 і 10.0 / 3. Поясніть різницю у виводі.

Коли виконаєш всі завдання, зроби скріншот результатів та кодів з VS Code і надішли вчителю в Classroom.
