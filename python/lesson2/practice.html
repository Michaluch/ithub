Завдання: "Керування даними"

Твоє завдання — застосувати знання про змінні для вирішення реальних задач розробника. Використовуй браузерний тренажер або своє середовище розробки.

1

Створення профілю гравця

Створи змінні для гри: nickname (рядок "Cyber_Kid"), level (число 10) та is_online (логічне True). Виведи їх через print.

python_editor.py
2

Обчислення площі

Створи дві змінні a та b зі значеннями 5 та 8. Створи третю змінну area, яка дорівнює їх добутку. Виведи результат.

area_calculator.py
3

Магія імен (Case Sensitivity)

Виправ помилку в коді, враховуючи регістр літер:

my_score = 100
print(My_Score)
💻

Завдання для VS Code / IDLE

Скопіюйте ці умови та реалізуйте їх у повноцінному файлі .py на своєму комп'ютері.

🚀 Задача "Обмін значеннями"

Створіть дві змінні: glass_water = "Вода" та glass_juice = "Сік". Напишіть код, який міняє їх значення місцями (так, щоб у воді був сік, і навпаки).

📊 Задача "Фінанси"

Створіть змінну balance = 5000. Опишіть покупку телефону за 1200 та отримання зарплати 2500, використовуючи математичні оператори присвоєння (наприклад -= або +=). Виведіть фінальний баланс.

🧬 Задача "Типізація"

Створіть змінну data = 100. Виведіть її тип. Потім змініть її значення на "100" (рядок) і знову виведіть тип. Спостерігайте, як працює динамічна типізація Python.

Коли виконаєш всі завдання, зроби скріншот результатів браузерних тестів та кодів з VS Code і надішли вчителю в Classroom.
