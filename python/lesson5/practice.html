Практика: Цикли

Закріплюємо while та for, вчимося рахувати кроки, працювати з range(), та керувати циклом через break/continue.

Порада: у браузерних завданнях перевірка — за шаблоном (пошук ключових фрагментів у відповіді).

1 Синтаксис while

Який варіант — правильний цикл while?

2 range() — 0..n-1

Напиши цикл, який виведе числа 0,1,2,3,4 (по одному в рядок).

3 Сума чисел (for)

Напиши код, який рахує суму чисел від 1 до 10 (включно) у змінну total.

sum.py

4 break чи continue?

Яке слово потрібно, щоб пропустити число 3 у циклі, але не завершувати цикл повністю?

5 Вкладений цикл (малюнок)

Напиши код, який виведе квадрат 3х3 зі зірочок (3 рядки по 3 *). Підказка: один цикл — по рядках, другий — по символах у рядку.

Завдання для VS Code / IDLE

Скопіюй умови та реалізуй у файлі .py.

🔁 1) Лічильник

Напиши програму, яка просить число n і друкує всі числа від 1 до n (через while), а потім те саме через for.

🎯 2) Гра “Вгадай число”

Комп’ютер загадує число 1–20, а користувач вгадує. Підказуй “більше/менше”. Рахуй кількість спроб. (Потрібен while.)

🧮 3) Таблиця множення

Виведи таблицю множення 1..9 (вкладені цикли). Можна друкувати рядками.

Коли виконаєш всі завдання, зроби скріншот результатів та кодів і надішли вчителю в Classroom.
