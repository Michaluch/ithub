Практична робота

Тема: Створення списків у Microsoft Word

Формат: практична робота

20–30 хвилин MS Word Марковані, нумеровані, багаторівневі списки

Мета роботи

Навчитись створювати та редагувати різні типи списків у Microsoft Word: марковані, нумеровані та багаторівневі. Розвинути навички структурованого подання інформації у текстовому документі.

Обладнання

Персональний комп’ютер з установленим Microsoft Word.

Інструкційна карта

Крок 1. Створення документа

  1. Відкрий програму Microsoft Word.
  2. Створи новий документ.
  3. У верхній частині документа введи заголовок: «Моє навчання та інтереси».
  4. Вирівняй заголовок по центру та зроби його напівжирним.

Крок 2. Створення маркованого списку

  1. Введи підзаголовок «Мої улюблені предмети».
  2. Натисни кнопку Маркери (Bullets) на вкладці Основне.
  3. Створи список із не менше 5 предметів.
Приклад:
  • Інформатика
  • Математика
  • Історія
  • Англійська мова
  • Географія

Крок 3. Створення нумерованого списку

  1. Нижче введи підзаголовок «Мій типовий навчальний день».
  2. Натисни кнопку Нумерація (Numbering).
  3. Створи список з 5–6 пунктів, що описують твій день.
Приклад:
  1. Прокинутися та підготуватися до школи
  2. Дорога до школи
  3. Навчальні заняття
  4. Виконання домашніх завдань
  5. Відпочинок

Крок 4. Створення багаторівневого списку

  1. Введи підзаголовок «Будова комп’ютера».
  2. Натисни кнопку Багаторівневий список (Multilevel List).
  3. Створи структуру за зразком.
Приклад:
  1. Апаратне забезпечення
    1. Процесор
    2. Оперативна пам’ять
    3. Жорсткий диск
  2. Пристрої введення
    1. Клавіатура
    2. Миша
  3. Пристрої виведення
    1. Монітор
    2. Принтер

Крок 5. Форматування списків

  1. Зміни стиль маркерів у першому списку.
  2. Застосуй інший стиль нумерації у другому списку.
  3. Зміни відступи одного зі списків.
  4. Перевір охайність документа.

Завдання підвищеної складності

Створи список на тему «Правила безпечної роботи за комп’ютером», використовуючи власні маркери.

Очікувані результати

  • створювати марковані списки;
  • створювати нумеровані списки;
  • створювати багаторівневі списки;
  • змінювати стиль маркерів та нумерації;
  • структурувати інформацію у текстових документах.
